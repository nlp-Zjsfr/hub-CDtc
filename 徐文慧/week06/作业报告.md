## 1. 任务与数据

| 项目 | 说明 |
|------|------|
| 输入 | 一条中文新闻标题 |
| 原始标签 | CLUE TNEWS，15 类（故事/文化/娱乐/体育/财经…） |
| 数据规模 | 训练 53,360 / 验证 10,000（其中 1,099 条与训练重复） |
| 评测口径 | **去重后的干净验证集**，固定 `seed=42` 抽 **500** 条；主指标 **Macro-F1** |

> 为什么要去重：验证集有约 11% 与训练集完全重复。不去重时，靠词面匹配的 TF-IDF 会「背答案」，分数虚高，对比不公平。

本作业做了两件事（对应「更换数据集或训练模型」）：

1. **训练模型**：从零训练 TextCNN（不依赖预训练权重）  
2. **更换标签口径（任务改造）**：把 15 类映射为投研 4 组主题（金融 / 产业 / 宏观 / 噪音），再做同口径对比

## 4. 分析与结论

1. **规则只能当下限 / 快筛**  
   15 类上 Macro-F1 仅 0.07，类别名命中率约 6.6%。标题套路固定时可挡一层，不能当主分类器。

2. **TF-IDF 是强基线**  
   15 类上 Macro-F1≈0.47，调参只涨约 0.3 个点。训练快、可解释，适合数据封闭或要秒级重训的场景。

3. **从零训练的 TextCNN 接近但未超过 TF-IDF**  
   2 万条、5 个 epoch 得到 F1≈0.46。说明：没有预训练知识时，短文本上「卷积网络」不一定赢「线性模型」；要明显拉开差距，通常需要 BERT 一类预训练模型。

4. **换标签口径比盲目换模型更划算（改造实验）**  
   收成 4 组后，TF-IDF F1 从 0.47 升到 **0.64**。业务上投研真正关心的是「主题组 + 是否相关」，而不是 15 个新闻细类。  
   → **换领域做分类，往往先改映射表，再谈换模型。**

5. **选型建议（结合本实验 + 课程对照）**

| 情况 | 建议 |
|------|------|
| 标签封闭、短文本、有标注 | 优先 BERT 微调（参考 F1≈0.54） |
| 内网 / 不能下预训练 / 要秒级重训 | TF-IDF |
| 没数据、先验证可行性 | API 零样本（参考≈0.47）；本地小模型易塌缩 |
| 上线 | 规则快筛 → 模型 → 低置信转人工（分流队列） |
